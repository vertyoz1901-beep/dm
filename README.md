# Сайт мебельной фабрики «Dарина»

Многостраничный сайт-каталог с корзиной и отправкой заявки на почту.
Без сборщиков и фреймворков — можно просто залить файлы на хостинг.

---

## 1. Что внутри

```
index.html            — главная
style.css             — все стили
script.js             — вся логика (шапка, корзина, каталог, анимации)
data.js               — каталог: товары, цены, отделки, размеры
send.php              — отправка заявки на почту (для хостинга с PHP)
icons/favicon.svg     — иконка сайта
images/products/      — фото товаров: <id-товара>.jpg
images/interior/      — фото интерьеров для галереи на главной
pages/
  catalog.html        — каталог с фильтром по разделам
  product.html        — карточка товара (открывается как product.html?id=kapriz)
  cart.html           — корзина и форма заявки
  about.html          — о фабрике
  delivery.html       — доставка и оплата
  faq.html            — вопросы и ответы
  contacts.html       — контакты
tools/download-images.js — перенос фотографий со старого сайта
```

## 2. Перенести фотографии со старого сайта

Нужен установленный Node.js 18 или новее. Из папки проекта выполните:

```bash
node tools/download-images.js
```

Скрипт скачает **все фотографии каждого товара** — по кадру на отделку:
`images/products/kapriz_1.jpg`, `_2.jpg` и так далее, плюс основное фото
`images/products/kapriz.jpg`. Разделитель — подчёркивание, а не дефис:
иначе `katrin-2.jpg` было бы одновременно вторым фото «Катрин»
и главным фото товара «Катрин 2». Ещё заберёт 12 интерьерных снимков
в `images/interior/` и логотип в `images/logo.png`.
Запускать можно повторно — уже скачанные файлы пропускаются.

Если какая-то позиция не скачалась, скрипт напишет её имя в конце —
положите файл вручную с тем же именем. Подойдут `.jpg`, `.png`, `.webp`.
Пока фото нет, карточка показывает аккуратную заглушку, вёрстка не ломается.

### Фото под каждую отделку

Скрипт сам пытается понять, какой кадр к какой отделке относится, и пишет
результат в `photo-map.js`:

```js
window.PHOTO_MAP = {
  'kapriz': { count: 8, colors: [3, 4, 5, 6, 7, 8] },
};
```

`count` — сколько всего фото у товара (по ним строится лента миниатюр
на странице товара). `colors` — номер фото для каждой отделки, по порядку
из `data.js`. Ноль означает «не распозналось»: сайт покажет основное фото,
а верный номер можно вписать руками.

Что распозналось, а что нет — видно в отчёте
`images/products/ФОТО-ПО-ОТДЕЛКАМ.txt`. Рядом с каждым номером указано имя
файла со старого сайта и его размер в пикселях, поэтому нужный кадр видно
сразу, не открывая папку.

Образцы цвета (маленькие квадратики рядом со списком отделок на старом сайте)
скрипт отсеивает: по размеру самого файла и по тому, насколько мелко картинка
выводится на странице. Иначе вместо кровати в карточку попадала бы
просто белая или коричневая заливка.

### Габаритные размеры

Скрипт заодно снимает со старого сайта строки «Спальное место» и «Габаритные
размеры» и складывает их в `dims-map.js`. Благодаря этому в карточке под
кнопками спального места показывается габарит кровати, и он меняется вместе
с выбранным размером. Править файл вручную обычно не нужно.

### Фото первого экрана

Положите свой снимок в корень папки `images` под именем `hero.jpg`
(подойдут также `.png` и `.webp`) — он появится в первом экране главной.
Лучше горизонтальный кадр интерьера, пропорции 4:3, ширина от 1400 px.

Если файла нет, сайт сам подставит фото кровати «Каприз», а если и его ещё
не скачали — первый интерьерный снимок. Какой товар считать запасным,
задаётся в `index.html` атрибутом `data-fallback` у картинки первого экрана.

### Что ещё настраивается без кода

- **Обложки категорий** — поле `cover` в `CATEGORIES` (`data.js`): указываете id
  товара, и его фото становится фоном плитки на главной. Отдельные файлы качать
  не нужно.
- **Основание, матрас, ящик, подушки** — поле `opts` у товара в `data.js`.
  Каждая группа превращается в ряд кнопок в карточке, выбор попадает в корзину
  и в письмо менеджеру:

```js
opts: [
  { n: 'Основание', v: ['Металлокаркас', 'Ламельное'] },
  { n: 'Ящик', v: ['Без ящика', 'Выкатной ящик'] }
]
```

### Чертежи в конец галереи

```bash
python3 tools/sort-photos.py
```

Среди снимков попадаются технические чертежи — контурный рисунок на белом.
Скрипт находит их по содержимому картинки и переносит в конец ленты фото,
чтобы карточка открывалась фотографией товара, а чертёж оставался доступен
последним кадром. После этого стоит пересобрать карту отделок (см. ниже).

### Как задать фото для отделки вручную

Файл `photo-map-names.json` хранит привязки именем файла:

```json
{ "kapriz": { "Орех": "whatsapp_image_2024-11-29_at_103231.jpg" } }
```

Это надёжнее номеров: если фотографии перекачать, удалить или переставить,
привязка не собьётся. Пересборка карты такие записи не затирает — она
дополняет их тем, что смогла определить сама.

### Пересобрать соответствие «отделка → фото»

Если фотографии уже скачаны, а номера в `photo-map.js` захотелось пересчитать
заново, сеть не нужна:

```bash
python3 tools/match-photos.py
```

Скрипт читает имена файлов со старого сайта из `images/products/_sources.json`,
сопоставляет их с названиями отделок из `data.js` и переписывает `photo-map.js`
и отчёт. Один файл достаётся только одной отделке, поэтому у разных цветов
не окажется одного и того же снимка.

Полезные ключи запуска:

```bash
node tools/download-images.js --fresh   # перекачать все фото заново
node tools/download-images.js --map     # пересобрать только карту, без сети
```

## 3. Куда приходят заявки

Заявка уходит на **darina_meb_ps@mail.ru** со всеми выбранными позициями
(название, отделка, размер, количество, сумма) и данными клиента.

Есть два способа отправки — выберите один в файле `script.js`, блок `ORDER` в самом начале.

### Вариант А — FormSubmit (по умолчанию, сервер не нужен)

Работает сразу, в том числе на бесплатном хостинге.
**Важно:** первая заявка после запуска придёт на почту как письмо-активация —
нужно один раз перейти по ссылке из него. После этого заявки идут обычным письмом.

### Вариант Б — свой PHP (если на хостинге есть PHP)

Файл `send.php` уже лежит в корне. В `script.js` замените:

```js
endpoint: 'send.php',
mode: 'php'
```

В самом `send.php` укажите адрес-отправитель на вашем домене
(строка `MAIL_FROM`) — иначе письма попадают в спам.
Все заявки дополнительно дублируются в файл `orders.log` рядом с сайтом,
чтобы ничего не потерялось, если почта хостинга подведёт.

Если отправка не прошла, сайт не теряет клиента: показывает ссылку
на письмо с уже подставленной заявкой и телефон менеджера.

## 4. Как менять цены и товары

Всё в `data.js`, код трогать не нужно.

```js
{
  id: 'kapriz',                  // совпадает с именем файла images/products/kapriz.jpg
  cat: 'krovati-massiv',         // раздел каталога
  title: 'Каприз',
  price: 21900,                  // цена за минимальный размер
  hit: true,                     // показывать на главной в «Хитах»
  colors: ['Слоновая кость', 'Капучино', 'Орех'],
  sizes: [{ label: '1400×2000', add: 0 }, { label: '1600×2000', add: 2400 }],
  specs: { 'Основание': 'Металлокаркас / ламельное' },
  desc: 'Короткое описание в карточке.'
}
```

- **Цена** — `price` плюс надбавка `add` выбранного размера.
- **Отделки** — просто названия; цвет образца берётся из справочника
  `FINISHES` в начале `data.js`. Появилась новая отделка — допишите её
  туда одной строкой: `'дуб сонома': '#C8A97E',`
- **Убрать товар** — удалите его блок; **добавить** — скопируйте соседний.
- **Скрыть цены** (например, для опта) — поставьте `price: 0`,
  в карточке появится «Цена по запросу».

## 5. Запуск

Залейте содержимое папки в корень сайта по FTP. Точка входа — `index.html`.
Локально сайт удобно открывать через любой простой сервер, например:

```bash
npx serve .
```

Открывать `index.html` двойным кликом тоже можно — работать будет всё,
кроме отправки заявки (браузер блокирует запросы с `file://`).

---

## 6. Проверено

- Раскладка от 320 px до 1920 px, без горизонтальной прокрутки
- Бургер-меню на телефонах, крупные кнопки под палец
- Корзина живёт между страницами и после перезагрузки
- Анимации отключаются, если пользователь выключил их в системе
- Цена никогда не остаётся нулём, даже если анимация не сработала
